Инструкция для iOS

Для установки вам придут два письма от Apple:

  1. Приглашение в App Store Connect — примите его, чтобы получить доступ к сборкам.
  2. Установите приложение TestFlight из App Store.
  3. Приглашение в TestFlight — после принятия первого письма, во втором нажмите «View in TestFlight».
  4. В TestFlight нажмите «Установить» рядом с иконкой приложения.

Инструкция для Android

  1. Скачайте APK-файл по кнопке ниже.
  2. Откройте файл и разрешите установку из неизвестных источников, если потребуется.
  3. Дождитесь завершения установки.
